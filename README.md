# Utility Belt (Cinto de Utilidades)
A ideia do software é fornecer facilitadores para o trabalho do desenvolvedor.

## Formatador SQL
Esse recurso do cinto de utilidades permite formatar uma query SQL.

Você copia o texto com a query SQL jogando-a para a área de transferência e usando um atalho específico(Ctrl+Q), você cola o texto já formatado.

Para que o recurso funcione dessa forma é preciso configurar o mapeamento de atalhos em ferramentas como o Microsoft Power Toys(https://learn.microsoft.com/pt-br/windows/powertoys/), disponível na Microsoft Store.
